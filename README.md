# Study-Jam-2.0-Building-With-Multimodel-AI
GDG Study Jam 2.0 — Build Real World AI Applications with Gemini and Imagen  Use Google's Gemini and Imagen AI to build three real apps in one session — generate images from text, ask AI to describe photos, and build a chatbot. All hands-on, all running live on Google's cloud. No AI experience needed, just bring a laptop and curiosity! 🚀
